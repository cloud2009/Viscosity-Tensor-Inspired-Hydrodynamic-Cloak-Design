PINN.rar is an example code of learning anisotropic viscosity tensor for hydrodynamic cloak design via PINN. 
The code running environment requires multiple GPUs, but it is ok to be modified to single GPU.
Training PINN is a kind of solving inverse problem with Navier-Stokes equation, that unknown viscosity tensor is determined to achieve the target cloak effect.
CAD design of hydrodynamic cloak is provided in CAD.rar, containing *.x_t format geometry.
More cases' code and data are upon request.
